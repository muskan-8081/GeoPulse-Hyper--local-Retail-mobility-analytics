\# GeoPulse – Power BI Retail Performance Dashboard



\## Project Overview

The dashboard analyzes simulated Delhi retail footfall and store performance using Power BI.



\## Data Sources

1\. Store Performance

2\. Store Hourly Footfall

3\. GPS Hotspots

4\. Location Suitability

5\. Cannibalization Summary



\## Data Relationships

\- Store Performance to Store Hourly Footfall

\- Store Performance to Cannibalization Summary



\## DAX Measures Created

\- Total Stores: Counts distinct store IDs.

\- Total GPS Pings: Calculates the total GPS pings across stores.



\## Dashboard Progress

The five datasets have been imported, the store relationships have been checked, and initial KPI measures have been created.



\## Data Limitation

The project uses synthetic GPS data and simulated store locations. Results represent a demonstration of retail analytics methods, not verified real-world customer behaviour.
